# Site de présentation — Arnaud Herr

Page statique servie par GitHub Pages.

- `index.html` — homepage (HTML + CSS + JS inline, aucune dépendance de build)
- `.nojekyll` — désactive le traitement Jekyll de GitHub Pages

## Publication

Settings → Pages → Source : « Deploy from a branch », branche `claude/service-site-revision-lmd2qu`, dossier `/ (root)`.
Une fois la branche fusionnée dans la branche par défaut, repointer Pages dessus.

## Développement

Aucun outil requis : ouvrir `index.html` dans un navigateur, ou

```
npx http-server . -p 8080
```

## Notes

- Typo : Plus Jakarta Sans (Google Fonts).
- Images : Unsplash en direct — à remplacer par des visuels hébergés avant mise en ligne définitive.
